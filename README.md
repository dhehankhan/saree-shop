# সেটআপ (একবারই করতে হবে)
1. supabase.com এ ফ্রি অ্যাকাউন্ট → New Project।
2. SQL Editor-এ `setup.sql` এর পুরো লেখা পেস্ট করে Run দিন।
3. Authentication → Users → Add user: আপনার ইমেইল ও পাসওয়ার্ড দিন (এটাই অ্যাডমিন লগইন)। Authentication → Sign In / Providers থেকে "Allow new users to sign up" বন্ধ রাখুন।
4. Project Settings → API থেকে Project URL ও anon public key কপি করে `config.js` এ বসান।
5. সব ফাইল GitHub রিপোতে আপলোড করে Settings → Pages চালু করুন।
অ্যাডমিন: আপনারসাইট/admin.html
টিপ: ভিডিও ছোট রাখুন (৫-২০ MB, MP4 H.264), ফ্রি প্ল্যানে প্রতি ফাইল সর্বোচ্চ ৫০ MB।
